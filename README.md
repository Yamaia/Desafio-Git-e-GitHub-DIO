Repositório criado para praticar o fluxo completo de **criação, atualização e sincronização** de um projeto com Git e GitHub. Ele reúne minhas anotações e exercícios das aulas.

## Objetivo
Praticar na prática: `init`, `add`, `commit`, `branch`, `merge`, `push`, `pull` e Pull Request.

## Comandos mais usados
| Comando | Para que serve |
|---|---|
| `git init` | Inicia um repositório local |
| `git status` | Mostra o estado dos arquivos |
| `git add` | Adiciona arquivos à área de stage |
| `git commit -m` | Registra uma versão |
| `git push` / `git pull` | Envia / baixa alterações do remoto |
| `git switch -c` | Cria e troca de branch |
| `git log --oneline --graph` | Mostra o histórico resumido |

## Aprendizados
- Versionamento permite voltar no tempo e trabalhar em paralelo sem medo de quebrar o projeto.
- Commits pequenos e com mensagens claras deixam o histórico legível.
- Branches + Pull Requests organizam a colaboração e a revisão de código.
